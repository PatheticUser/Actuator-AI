Section 02 — building

Why build on Qwen today

Open weights, real license

Apache 2.0 on the open line. Download, fine-tune, ship commercially, self-host at zero per-token cost.

Cheap enough to demo all day

Flash tiers start near $0.05 per million input tokens; Plus around $0.40 in. Your hackathon spend is pennies.

Multimodal out of the box

Text, image and video in. Voice through the Omni and Audio lines. One vendor, not three.

OpenAI-compatible API

Change two lines — base URL and key — and most existing code just works.

Do this now — you already have access

Call Qwen through ModelScope

Everyone here has a ModelScope token. This exact snippet works with your token — swap in <MODELSCOPE_TOKEN> and run.

More ways to call Qwen:

  • ModelScope — OpenAI-compatible, your token, no billing setup. Use this today.
  • Model Studio / DashScope — Alibaba Cloud's official endpoint, per-token billing.
  • OpenRouter — one key across many providers.
  • Local — Ollama, vLLM or Hugging Face for the open weights. No key, no network.

The old free OAuth API tier ended April 2026 — ignore tutorials that promise it.

from openai import OpenAI

client = OpenAI(
    base_url='https://api-inference.modelscope.ai/v1',
    api_key='<MODELSCOPE_TOKEN>', # ModelScope Token
)

response = client.chat.completions.create(
    model='Qwen-Ambassador/Qwen3.7-Max', # ModelScope Model-Id, required
    messages=[
        {
            'role': 'user',
            'content': '你好'
        }
    ],
    stream=True
)
done_reasoning = False
for chunk in response:
    if chunk.choices:
        reasoning_chunk = chunk.choices[0].delta.reasoning_content
        answer_chunk = chunk.choices[0].delta.content
        if reasoning_chunk != '':
            print(reasoning_chunk, end='', flush=True)
        elif answer_chunk != '':
            if not done_reasoning:
                print('\n\n === Final Answer ===\n')
                done_reasoning = True
            print(answer_chunk, end='', flush=True)
